# Fitness

Мобильный трекер тренировок по согласованному графитовому макету с лаймовыми акцентами.

Приложение: https://fitness-valera.marchenkovy99.chatgpt.site

## Возможности

- Две полные тренировки А/Б с программой пользователя: 6 и 7 силовых упражнений. Разминка и заключительная ходьба показаны отдельно.
- Подходы и повторения сохраняются для каждой тренировки отдельно, в том числе для общего упражнения «Жим от груди».
- Статусы «Не отмечено», «Выполнено», «Пропущено»; повторное нажатие снимает отметку. Отметки разделены по тренировке и локальной дате устройства.
- Библиотека с поиском, просмотр упражнения, создание и редактирование; произвольные области тела и описание.
- Обложки из файла или по прямой http/https-ссылке; загруженные фотографии уменьшаются перед сохранением.
- Черновики формы, локальное сохранение между открытиями, экспорт и восстановление JSON-копии.

Данные хранятся в localStorage конкретного браузера и адреса. Облачной синхронизации нет. При очистке данных браузера потребуется резервная копия. Хранилище ограничено; ошибки сохранения отображаются явно. Удалённые фото требуют доступной ссылки. Отметки не переносятся автоматически на следующий день.

Назначения и описания перенесены из программы пользователя. Обложки сгенерированы и служат только иллюстрациями, не инструкцией по технике. Дополнительные инструкции не добавлены. Румынская тяга сохранена с условием про поясницу и уверенную технику.

## Календарь и веса

У каждого упражнения в тренировке есть поле веса в кг. Поддерживаются десятичные точка и запятая, а также нулевой вес. Значения сохраняются сразу, отдельно для тренировки А/Б и даты. Одна запись каждого типа тренировки в день.

Под списком упражнений находится отметка «Тренировка выполнена». Она записывает в календарь состав занятия, названия, описания, подходы, повторения, веса и индивидуальные статусы. Неотмеченные упражнения не засчитываются автоматически. В календаре можно выбрать день, открыть тренировку и раскрыть описание каждого упражнения. Внесённые позже изменения программы не переписывают исторический состав. Явные изменения сегодняшних весов и статусов отражаются в уже завершённой записи.

Копии JSON содержат календарь и веса. Данные первой версии автоматически дополняются новыми полями, существующие упражнения и отметки сохраняются.

## Запуск

Нужен любой статический HTTP-сервер, например `python3 -m http.server 8080`. Открыть `http://localhost:8080`. Зависимостей для приложения нет. Прямое открытие `index.html` через file:// не поддерживает ES-модули.

Проверки: `npm test` и `npm run check`. Сборка для хостинга: `node scripts/build.mjs` (выход в `dist/`). Файлы используют относительные пути и подходят для GitHub Pages, включая подкаталог `/Fitnes/`.

На iPhone можно добавить страницу на экран «Домой» через меню «Поделиться» Safari. Для загрузки приложения нужен интернет; автономная загрузка оболочки без сети в этой версии не реализована.

## Проверки первой версии

Автоматически проверены состав программы, сохранение, разделение отметок, редактирование общего упражнения и валидация импорта/обложек. Синтаксис всех JS-модулей проверен Node.js. Полноценная визуальная и сенсорная проверка в мобильном браузере пока не проведена.
