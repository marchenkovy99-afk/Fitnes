# Fitness, версия 1

Основа: последний согласованный макет с тремя экранами. Графит #151719, лайм #d6f574, кириллица, карточка с обычным описанием без шагов. Мобильный интерфейс, на большом экране сохраняется удобная ширина.

План реализации: 1) данные двух тренировок и тесты модели; 2) список, библиотека, просмотр и форма создания/редактирования; 3) проверки, загрузка исходников в пользовательский Fitnes и конфигурация GitHub Pages.

Файлы: data.js содержит исходную программу без изменения нагрузки; model.js отвечает за сессии, статусы, валидацию и сохранение; app.js за интерфейс; styles.css за дизайн; tests/model.test.js за поведение.

Отметки разделены по дате и тренировке. Одно упражнение может входить в обе тренировки с разным количеством подходов. Локальное сохранение без аккаунтов и облачной синхронизации. Описание передано пользователем, дополнительных инструкций по технике не сочиняем. Разминка и ходьба отображаются отдельно от нумерованных силовых упражнений.

Проверки: полный состав программы, раздельность А/Б и дат, повторный выбор снимает статус, редактирование не теряет назначения, неподходящие URL, поврежденное хранилище, ошибка записи. Все пользовательские строки экранируются; фото по внешней ссылке могут быть недоступны, предусмотрена замена.


Календарь: отдельный calendar.js с сеткой недель от понедельника. weights хранит нагрузки по ключам дата:план, history содержит снимки завершённых занятий. Завершение с неотмеченными упражнениями требует предупреждения. Изменение программы не меняет снимки, а явные изменения веса/статуса сегодня обновляют соответствующий результат.
